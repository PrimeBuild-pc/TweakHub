# TweakHub: next release (not released yet)

Changes merged after v1.6.1. They are kept for a larger release; move them into the release notes when the version is tagged.

- External tools: NVIDIA VBIOS Vix Editor (GPU & Display). The description carries the warnings: edited ROMs fail the original signature and must never be flashed with nvflash, raising power, current or voltage can damage hardware, many fields are experimental, binaries are unsigned. TweakHub only opens the project page.
- Devices → Affinity: "Suggested layout by role" gives graphics, USB, network and audio one physical core each, outside core 0, chosen from the CPU topology (P-cores only on hybrid CPUs; with several L3 caches the one without 3D V-Cache, or the one without CPU 0 when equal; network and audio share a core up to 6 cores). Each device can be unticked in the preview. Only the affinity changes, MSI and priority stay as they are; one backup and one elevation for the whole layout, undone per device with the existing restore. HD Audio controllers are now recognised by their PCI class code. Network RSS is not changed. The audio core goes only to a sound card in use: the HDMI/DisplayPort audio of the graphics card and controllers whose audio devices are all disabled are skipped, and when none is left the preview explains that USB audio (headsets, DACs, audio interfaces) follows its USB controller's core.
- Suggested layout, audio and USB: the USB controller that carries the default playback or recording device (DAC, audio interface, USB headset) gets the audio core when no mouse or keyboard shares it; a headset's own media keys do not count as a keyboard. The preview lists what is plugged into each USB controller (mouse, keyboard, camera, default audio) and, when the audio device shares a controller with input, suggests a port on a free controller. It warns when the default playback or recording device uses a front-panel jack of the case (from the driver's jack description) and suggests the rear motherboard jack. It also shows the load of the chosen cores and CPU 0 measured over 2 seconds (busy share, interrupts and DPC, interrupts per second, language independent) and warns when a chosen core is already busy; the cores are not moved automatically, because an idle sample is not the load of a game.
